# NYC Model Club — Open to All Models

Open-access creative platform for models and industry talent, backed by New York City Model Management.

View your app in AI Studio: https://ai.studio/apps/775a4bf4-09a5-4673-bf82-196176cbaae5

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
